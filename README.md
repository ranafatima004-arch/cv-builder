# AI CV Builder

An AI-powered CV and Resume builder application built with React, Vite, and Tailwind CSS.

## 🚀 Live Demo
Check out the live application here: [AI CV Builder Live](https://cv-builder-au7h.vercel.app)

## ✨ Features
- Fast and responsive UI
- AI-driven CV generation
- Easy export to PDF

## 🛠️ Tech Stack
- React.js
- Vite
- Tailwind CSS
- Vercel (Deployment)
